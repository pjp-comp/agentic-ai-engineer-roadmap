# Stage 13 — Open Source + Portfolio

Ship autonomous agents publicly · write architecture docs · record demos · contribute to libs

## Why this matters

Everything in Stages 1–11 is proof of skill only once someone else can see it working. A portfolio piece that's live, documented, and has a recorded failure mode you fixed is worth more than a private repo — it shows judgment under real constraints, not just code that runs once.

## Brief

Take the agent built across Stages 5–11 and ship it: public repo, a README with an architecture diagram, a 3–5 minute demo recording including a deliberately induced failure (rate limit, bad tool call) and how it degrades. Then make one real contribution to a library you used (LangGraph, CrewAI, an MCP server) — a docs fix counts as a start.

## Done when

A stranger can read your README, understand what the agent does and why it's built that way, and run it themselves.
